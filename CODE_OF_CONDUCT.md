# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and harassment-free community.
Participants should be constructive, assume good faith, respect different
experiences, and focus criticism on ideas and behavior rather than people.

Unacceptable behavior includes harassment, discrimination, intimidation,
personal attacks, doxxing, unwanted sexual attention, and publishing private
information without permission.

## Enforcement

Report conduct concerns privately to the maintainer using the security contact
in [`SECURITY.md`](SECURITY.md). Reports will be reviewed promptly and handled
confidentially where possible. Maintainers may remove comments, close issues or
pull requests, or restrict participation when necessary to protect the
community.

This code of conduct applies in project spaces and whenever someone is
representing the project publicly.
