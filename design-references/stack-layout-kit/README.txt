STACK roomier application preview

Open index.html directly in a browser. No external requests, fonts or dependencies. Light mode is default; switch to dark mode with the header button. Search the fleet and select a character. On narrow screens, Back to fleet returns from the chat preview.

The layout and text are editable HTML/CSS. Character assets are extracted raster concepts from the image model, NOT native SVG artwork. STACK-wide-light.svg and STACK-wide-dark.svg are editable composition files that embed raster avatar images; do not mistake them for native vector characters.

The original D STACK design is used, not D1. The new12-member sheet varies anatomy, including broad shoulders, tall narrow frames, squat bodies, an asymmetric build, barrel and inverted-triangle torsos, an oversized head, long legs, square and tapered bodies, an offset head and a three-legged build.

Actual32/40/48px checks were inspected on light and dark. At32px, silhouette differences remain more reliable than facial detail. The roomier layout uses48-52px avatar slots. Before production, the characters need deliberate vector simplification, optical small-size variants and cleaned alpha edges; this kit does not claim those steps are complete.

The image-model phone preview is a first composition. The editable desktop layout shows eight visible rows; the responsive HTML includes all12 as a scrollable page. All content is synthetic. No app files were changed, no deployment or server was started.
