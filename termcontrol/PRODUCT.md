# TermControl mobile

The owner explicitly wants the original dark TermControl design and shell retained. Visual changes are scoped to the message/conversation region: readable user/agent messages, native tables, Copy, inline actual requests, and the recorded Freelance Desk day. The broad light inbox/navigation redesign was an incorrect expansion of scope and has been reverted.

The list and header retain their original structure and palette. Technical startup instructions must not become giant titles. Last used means explicit owner conversation use; background output, heartbeat and polling are not use. Unknown history stays unknown. Phone use persists on the existing authenticated bridge across phones; exact desktop focus source integration remains coordinated separately.

Source transcripts and real per-pane requests/exports are authority. Important approvals and actionable errors stay visible. Routine proven loader/hook or explicit transcript metadata is collapsed with accessible exact details and Copy; genuine answers and literal code remain. Pending-answer navigation must open/focus real choices and report honest failures. No click manufactures a submission or confirmation.

Live custom dispatch remains disabled until consented installed-Claude form/result acceptance. No real answer or planning mutation is used for testing. Only reversible existing-route TermControl deployment is authorized; desktop and daemon sessions must be preserved.
